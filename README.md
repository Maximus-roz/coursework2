# Курсовая 2

## О проекте (Description)
В проекте реализована программа, которая собирает данные о самолетах в воздушных 
пространствах тех стран, которые выберет пользователь.

Чтобы получить географические координаты стран,используется API nominatim.openstreetmap.org, 
информацию о самолетах — API opensky-network.org.

## 🚀 Быстрый старт (Installation & Run)

### Требования
- Python 3.8+ 

### Установка

git clone https://github.com/Maximus-roz/PythonProject.git
cd src
pip install -r requirements.txt

в папке tests содержатся модули для тестирования проекта
